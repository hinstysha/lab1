### 4. Git hook для flake8
Хук `pre-commit` проверяет код линтером перед коммитом.
**Инструкция по установке:**
1. Убедитесь, что установлен flake8: `pip install flake8`
2. Назначьте директорию `hooks/` системной папкой для хуков:
   `git config core.hooksPath hooks`
